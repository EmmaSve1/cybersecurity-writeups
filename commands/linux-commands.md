# Linux-kommandon

En löpande lista över Linux-kommandon jag lär mig. 

| Kommando        | Vad det gör                                                                                                               | Exempel                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| pwd             | Det visar vart i systemet jag är                                                                                          | Jag vill veta om jag är i rätt mapp                                                                                                 |
| ls              | Vilka filer och mappar som finns där jag är                                                                               | För att se så den mapp jag söker efter ligger där jag tror                                                                          |
| ls -l           | Ger mer detaljer om filerna och mapparna där jag är nu                                                                    | Om jag vill veta hur stor en fil är                                                                                                 |
| ls -al          | Visar alla gömda filer                                                                                                    |                                                                                                                                     |
| cd              | För att flytta runt mig i systemet, det är muspekaren kan man säga                                                        | Om jag vill förflytta mig till tex dokuments - cs /home/kali/documents                                                              |
| cd ..           | För att gå tillbaka ett steg                                                                                              | Om jag har förflyttat mig men sedan vill gå tillbaka där jag var innan                                                              |
| find ~<br>-name | För att hitta var en specifik fil eller dokument ligger på systemet                                                       | Om jag behöver läsa ett specifikt dokument som jag har namnet på men vet inte vart i systemet den är kan jag använda detta kommando |
| cat             | för att läsa en fil                                                                                                       |                                                                                                                                     |
| whoami          | För att kolla vem jag är inloggad som                                                                                     |                                                                                                                                     |
| uname -a        | För att se vilket system jag är på samt detaljer                                                                          |                                                                                                                                     |
| uname           | För att enbart se Operativ systemets namn tex Linux                                                                       |                                                                                                                                     |
| df -h           | För att kollar disk användning samt tillgängligt utrymme, -h betyder mänskligt läsbart och visar med enkelhet tex 5GB osv | Om jag vill ha reda på hur mycket utrymme jag har innan jag börjar arbeta och installera applikationer.                             |
